# Задача Facility Location

## Решение 1

Чтобы получить какой-то baseline, я написал простой жадный алгоритм. Он обрабатывает каждого клиента по порядку,
минимизируя стоимость его добавления. То есть для каждого клиента для каждого магазина назначается псевдоцена:

1. если магазин ещё не открыт, то псевдоцена - это стоимость открытия + расстояние
2. если магазин уже открыт, то псевдоцена - это расстояние

Человеку назначается магазин с минимальной псевдоценой. Такое решение берёт пороги только в первой задаче, но хотя бы
работает!
