# Дискретная оптимизация

## Где искать x?

🧑‍💻 **Код солверов**: Солверы можно найти в `src/{название задачи}/solvers`.

📝 **Отчёты**: Отчёт можно найти в `src/{название задачи}/report.md`.

🔢 **Файлы с решениями**: В репозитории настроены GitHub Actions. Он автоматически собирает проект и запускает
`src/{название задачи}/grade.cpp` для всех задач. После этого полученные решения сохраняются в качестве артефактов.

## Структура проекта

Для каждой задачи создаётся отдельная ветка с соответствующим именем. Код находится в папке `src`. В папку `tasks`
кладутся файлы заданий. Они большие и их много, поэтому я загружаю на GitHub только те, что оцениваются.

Чтобы запустить код, достаточно из корня проекта выполнить:

```shell
mkdir build
cd build
cmake ..
cmake --build . --target {название задачи}
./{название задачи}
```
