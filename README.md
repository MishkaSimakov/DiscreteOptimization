# Дискретная оптимизация

## Где искать x?

🧑‍💻 **Код солверов**: Солверы можно найти в `src/{название задачи}/solvers`.

📝 **Отчёты**: Отчёт можно найти в `src/{название задачи}/report.md`. **Важно**: последняя версия решения может быть не
наилучшей, в отчётах указаны ссылки на наилучшие версии решений.

🔢 **Файлы с решениями**: В репозитории настроены GitHub Actions. Проект автоматически собирается и для каждой задачи
запускается `src/{название задачи}/grade.cpp`. После этого полученные решения сохраняются в качестве артефактов. Чтобы
их скачать, достаточно зайти во
вкладку [Actions](https://github.com/MishkaSimakov/DiscreteOptimization/actions?query=branch%3Amaster), затем зайти в
последний запуск, пролистать вниз и скачать артефакт с названием `all-results`. Также в отчётах можно встретить ссылки,
которые ведут на результаты запусков.

Обратите внимание, что для каждой задачи сделана отдельная ветка. Самые новые экспериментальные решения можно найти там.
Стабильные и полноценно работающие решения вливаются в master.

## Самостоятельная сборка

Чтобы запустить код, достаточно из корня проекта выполнить:

```shell
mkdir build
cd build
cmake ..
cmake --build . --target {название задачи}
./src/{название задачи}_grade {название подзадачи}
```

В последнем шаге например можно запустить так (из папки `build`):

```shell
./src/setcover_grade sc_6_1
```

## Политика использования ИИ

Я считаю, что честно использовать ИИ для визуализации. Я использовал Claude, чтобы построить красивую панель, где можно
сравнивать результаты работы солвера на разных коммитах. В код, написанный ИИ, добавлен Claude как соавтор. Весь
остальной код написан моими руками.
